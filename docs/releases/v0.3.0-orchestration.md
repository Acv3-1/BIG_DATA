
## Limitaciones conocidas

- Airflow en modo `standalone` con SQLite: pensado para uso local, no para producción.
- Curated tarda ~15 min en aparecer por el watermark de Spark; por eso su ausencia es solo advertencia.
- Pruebas de Spark: solo se ejecutan donde hay PySpark y Java (no en el CI básico).
