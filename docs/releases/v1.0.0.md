# RapidGo - Variante 10: Inventario y fulfillment - v1.0.0

Release final del proyecto: pipeline Big Data end-to-end para detectar
agotados y demoras de picking en comercios aliados.

**Equipo:** Juan Acevedo, WIlson Cristancho, Santiago Mahecha
**Video de la solución (máx. 10 min):** [enlace al video]

## Qué incluye

- **Generación y transporte de eventos:** producer en `producer/` y Kafka
  (topic `inventario-fulfillment`, key `store_id`, [N] particiones).
- **Procesamiento:** Spark Structured Streaming con [resumen de transformaciones,
  ventana y alertas], persistido en Parquet (Raw -> Processed -> Curated).
- **Orquestación:** DAG `rapidgo_variante10` en Airflow con 5 tasks, reintentos
  y XCom; genera el reporte de KPIs.
- **KPIs:** stockouts, picking promedio y pedidos incompletos.
- **Alertas:** stock crítico y picking fuera de tiempo.
- **CI/CD:** GitHub Actions con quality gate (sintaxis, pruebas, DAG, Docker Compose).

## Cómo ejecutarlo

Pasos completos en el [README](../../README.md). Resumen:

1. `docker compose up -d`
2. `python -m producer.producer --count [N]`
3. Abrir Airflow en [URL] y ejecutar el DAG `rapidgo_variante10`.
